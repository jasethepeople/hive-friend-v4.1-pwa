# 🐝 Hive Friend v4.1

Planetary Swarm Dashboard for Hive Foundation.

## Quick Start

```bash
npm install
./start.sh
```

Then open the printed URL on your phone and tap **Add to Home Screen**.

## Features

- **PWA**: Install to home screen, works offline
- **WebSocket**: Real-time streaming from all clusters
- **Touch Gestures**: Pull-to-refresh, swipe navigation
- **Haptic Feedback**: Vibration on every action
- **Theme**: Dark / Light / Auto
- **Mobile**: Bottom sheet controls, responsive layout
